# API Reference

This section is a placeholder until the VR Framework SDK documentation generator
is wired up. Everything under `api/` is meant to be **generated output** - the
Docusaurus side is already configured for it.

## How this section is wired

| Piece | Where |
| --- | --- |
| Docs plugin instance | `docusaurus.config.ts` → `plugins[]`, `id: 'api'` |
| Content directory | `api/` |
| Route | `/api` |
| Sidebar | `sidebarsApi.ts` (autogenerated from the folder tree) |

Drop generated Markdown (or MDX) files into `api/` and they appear in the
sidebar automatically - no config change needed. Nested folders become sidebar
categories; add a `_category_.json` next to them to control the label and order.

## Plugging in a generator

The right tool depends on what the SDK ships:

- **C# / Unity source** → [DocFX](https://dotnet.github.io/docfx/) with a
  Markdown output template, or [Doxygen](https://www.doxygen.nl/) +
  `moxygen` to convert XML to Markdown. Point the output at `api/`.
- **TypeScript SDK** → [`docusaurus-plugin-typedoc`](https://typedoc-plugin-markdown.org/plugins/docusaurus)
  writes Markdown plus its own sidebar file straight into this instance.
- **OpenAPI spec** → [`docusaurus-plugin-openapi-docs`](https://github.com/PaloAltoNetworks/docusaurus-openapi-docs).

Whichever it is, the generation step belongs in `package.json` as a
`gen:api` script that runs before `build`.

:::note
Generated files should not be hand-edited. Once the generator is in place,
consider adding `/api/**` (except this page) to `.gitignore` and generating in
CI instead.
:::
